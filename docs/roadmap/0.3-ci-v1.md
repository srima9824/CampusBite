# 0.3 Simple CI
Branch: `feat/0.3-ci-v1` · ui_review: none · Depends on: 0.2

Read AGENTS.md first.

## Goal
Keep one small GitHub Actions workflow that runs the project's existing lint and unit-test commands.

## Non-goals
No E2E, Docker build, security scanning, dependency review, commit/title checks, or extra workflows in this slice.

## Deliverables
- `.github/workflows/ci.yml` running the direct project checks on pushes and pull requests

## Acceptance
- The workflow runs only the existing lint and unit-test commands.
- Action versions are pinned and the workflow contains no secrets.

## Commits
- `ci(ci): add simple lint and test workflow`
